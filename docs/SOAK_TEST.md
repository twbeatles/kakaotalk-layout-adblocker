# Soak Test & Manual Release Verification Guide

> 대상: KakaoTalk Layout AdBlocker v11.1.x (Rust Native)  
> 목적: 최종 릴리스 전 장시간(1시간 이상) 실사용 및 모든 사용자 상호작용 검증.

---

## 1. 사전 준비 및 환경 구성

1. 최신 카카오톡 PC 버전 설치 및 로그인 완료 상태 확인.
2. 릴리스 바이너리 준비:
   ```powershell
   .\scripts\build_release.ps1 -NoSign
   # dist\KakaoTalkLayoutAdBlocker_v11.exe 생성 확인
   ```
3. 프로세스 모니터(작업 관리자 또는 Process Hacker/Process Explorer)를 열어 `KakaoTalkLayoutAdBlocker_v11.exe`의 Working Set, Private Bytes, CPU 사용률을 관찰할 수 있도록 준비합니다.

---

## 2. 매뉴얼 검증 체크리스트 (Manual Checklist)

### A. 기본 광고 차단 및 레이아웃 검증
- [ ] **메인 창 하단 배너**: 친구 목록 및 채팅 목록 탭에서 하단 배너 광고가 완전히 사라지고, 목록 뷰가 하단 끝까지 꽉 차게 확장되는지 확인.
- [ ] **뷰 리사이즈 정상 여부**: 목록 스크롤이 부드럽게 동작하며, 스크롤바가 화면 하단 끝까지 올바르게 닿는지 확인.
- [ ] **검은 화면(Black Screen) 방지 확인**: 카카오톡 창 크기를 최소/최대화 및 드래그로 조절할 때 화면이 검게 변하거나 깜빡이지 않는지 확인.
- [ ] **독립 팝업 광고**: 카카오톡 실행 시 또는 사용 중 노출되는 우측 하단 알림형 광고 팝업(`AdFitWebView`)이 자동으로 닫히는지 확인.

### B. 탭 및 창 전환 상호작용
- [ ] **친구 탭 <-> 채팅 탭 이동**: 탭 전환 시 레이아웃 깨짐이나 광고 잔상이 남지 않는지 확인.
- [ ] **개별 대화방 열기**: 여러 개의 개별 채팅방을 열었을 때 대화방 창이 영향을 받지 않고 정상 작동하는지 확인.
- [ ] **잠금 모드 전환 (`LockModeView`)**: 잠금 모드로 전환했을 때 하단 공백 없이 잠금 화면이 창 전체를 덮는지 확인.
- [ ] **최소화 및 복원**: 카카오톡을 트레이로 최소화했다가 다시 열었을 때 광고가 다시 나타나지 않고 즉시 차단 상태를 유지하는지 확인.

### C. 트레이 메뉴 및 동적 토글 검증
- [ ] **차단 끄기 (OFF)**: 트레이에서 `차단 끄기` 클릭 시 숨겨졌던 하단 광고가 원래 크기와 위치로 즉시 다시 나타나는지 확인.
- [ ] **차단 켜기 (ON)**: 다시 `차단 켜기` 클릭 시 딜레이 없이 즉시 광고가 제거되는지 확인.
- [ ] **공격 모드 (Aggressive Mode)**: 체크/해제 시 정상 동작 및 설정 파일(`layout_settings_v11.json`)에 즉시 반영되는지 확인.
- [ ] **시작프로그램 등록**: 체크 시 레지스트리(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`)에 올바른 인자(`--startup-launch --minimized`)로 등록되는지 확인.
- [ ] **시작프로그램 재부팅**: 등록 후 실제 재부팅(또는 로그아웃/로그인) 시 트레이 아이콘이 다시 나타나는지 확인. Windows 시작앱에서 해당 항목이 켜져 있는지도 확인.
- [ ] **로그 폴더 열기**: 파일 탐색기로 `%APPDATA%\KakaoTalkAdBlockerLayout\` 폴더가 열리고 `layout_adblock.log` 파일에 실행 로그가 정상 기록되는지 확인.
- [ ] **중복 실행 방지**: 프로그램 실행 중 다시 EXE를 더블클릭했을 때 알림 대화상자("프로그램이 이미 실행 중입니다") 노출 후 기존 인스턴스에 영향 없이 안전 종료되는지 확인.
- [ ] **종료 (Exit)**: `종료` 클릭 시 모든 광고 창이 원래 상태로 안전하게 복원된 뒤 프로세스가 정상 종료되는지 확인.

### D. 생명주기 및 복원력 (Resilience)
- [ ] **카카오톡 종료 후 재실행**: blocker를 켜둔 상태에서 카카오톡을 완전히 종료하고 다시 실행했을 때 새 프로세스를 즉시 감지하여 광고를 차단하는지 확인.
- [ ] **카카오톡 미실행 상태에서 blocker 부팅**: 카카오톡이 켜져 있지 않을 때 blocker가 조용히 대기하며(CPU 0%), 카카오톡이 켜지는 순간 반응하는지 확인.

### E. 자동 업데이트 파이프라인 검증
- [ ] 트레이에서 `업데이트 확인` 클릭 시 최신 버전 안내 팝업 노출 확인.
- [ ] 새 버전 매니페스트 감지 시 대화상자 확인 후 다운로드 -> 헬퍼 실행 -> 앱 종료 -> 교체 -> 자동 재실행 파이프라인 동작 확인.

## 3. 1시간 장시간 Soak Test 관찰 항목

실제 카카오톡을 평상시와 같이 1시간 이상 사용하면서 다음 이상 증상이 없는지 확인합니다:
1. **메모리 누수 (Memory Leak)**: Working Set이 4~8MB 범위를 벗어나 지속적으로 증가(수십 MB 이상)하지 않는지 확인.
2. **CPU 폭주 (CPU Runaway)**: 카카오톡을 사용하지 않는 유휴 상태에서 CPU 점유율이 0.0%를 유지하는지 확인 (이벤트 루프 스핀 없음).
3. **오탐(False Positive) 차단**: 친구 프로필, 사진 뷰어, 보이스톡, 이모티콘 샵 등 정상 카카오톡 기능 창이 잘못 닫히거나 숨겨지지 않는지 확인.
4. **로그 폭주 (Log Spam)**: `layout_adblock.log` 파일 크기가 수십 MB 이상으로 비정상 증가하지 않는지 확인.
